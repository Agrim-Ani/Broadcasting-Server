⚡ Broadcast Sign in
WebSocket-powered · Open source

One message.
Everyone gets it.

The idea is simple. Your message goes up to the server once — the server sends copies down to everyone in the room at the same moment. That's a broadcast server. This app is what that looks like when you put a UI around it.

How it works

01

You send a message

Your browser keeps a WebSocket connection open — a persistent pipe to the server. Hit send and the message travels through it immediately. No HTTP round-trip, no handshake on every keystroke.

→
02

The server broadcasts it

The server receives it once, then fans it out — writing a copy down every open socket in that room at the same time. One message in, many copies out. That's the broadcast part.

→
03

Everyone sees it now

The message appears on every screen in the room at the same moment. Nobody refreshed. Nobody polled. It just arrived. That's the whole point.

What you get

⚡

Real-time delivery

WebSocket, not polling. Messages land in milliseconds, not on the next interval tick.

🔗

Invite links

Share a link, not credentials. Anyone with it can preview the room and join with one click.

🟢

Live presence

Online indicators update the moment someone connects or drops. No stale state, ever.

🛡

Room controls

Owners can rename or delete rooms. Everyone else can leave. Clean by design.
